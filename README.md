# Adnet Print Tracker & ERP

Cloud-based, role-governed workflow tracking application for print production, design approvals, and accounts billing.

## Tech Stack
- **Frontend / Framework:** Streamlit (Python)
- **Database:** Supabase (PostgreSQL - Mumbai region)
- **Email Service:** Gmail SMTP automated reporting

## Features
- **Strict Data Masking:** Non-financial roles cannot view commercial rates or invoice amounts.
- **Many-to-Many RBAC:** Flexible module assignment across geographically distributed teams.
- **Executive Oversight:** Instant, daily 6:00 PM summaries, Saturday 10:00 AM weekly scorecard, and bottleneck escalation.
